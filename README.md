# Bumble Wash - Premium Laundry Care & Smooth Scroll Website

A modern, high-performance website for **Bumble Wash**, featuring a cinematic 300-frame canvas scroll animation that seamlessly takes users on a journey through the storefront as they scroll down the page.

## ✨ Key Features
- **Cinematic Canvas Scroll Animation**: Smooth 300-frame image sequence with fluid spring interpolation (`0.085` damping factor) for an Apple-style glide.
- **Modern Luxury Dark Aesthetic**: Glassmorphism cards with translucent frosted glass, subtle neon accents, and high-contrast typography.
- **Complete Website Layout**:
  - **Navigation Header**: Single-line capsule navbar with desktop buttons and mobile hamburger drawer.
  - **Hero Section**: Clean headline (*Fresh Clothes. Happier Days.*) with cold-white bold subheading and dual CTAs.
  - **5 Feature Cards**: Advanced Fresh, Professional Touch, Customized Options, Superior Clean, and Exceptional Quality.
  - **Services Section**: Editorial Playfair italic typography (*Laundry Care Made Effortless*), 4 detailed service cards, and certification standards.
  - **Stats Section**: Infographic glowing pillar meters (*10K+ Garments, 98% Satisfaction, 500+ Customers, 24/7 Booking*).
  - **Reviews Section**: Verified customer testimonials with 5-star ratings and verified indicators.
  - **Tailored Care Section**: Featured service cards with bespoke badges.
  - **Contact Section & Footer**: Complete location in Mumbai, helpline (`98340 54348`), email (`bumblewash26@gmail.com`), Instagram link, one-click copy buttons, and Back to Top navigation.
- **Interactive Modals**:
  - Interactive "Send an Enquiry" booking popup.
  - Toast feedback notifications.
  - Floating Back-to-Top quick jump.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally using any static web server:

```powershell
# Using built-in PowerShell server
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

Or open directly with Python / Node if available:
```bash
npx serve .
# or
python -m http.server 3000
```
