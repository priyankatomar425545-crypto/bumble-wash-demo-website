# Bumble Wash - Premium Laundry Care (React + Vite)

A modern, high-performance React application for **Bumble Wash**, featuring a cinematic 300-frame canvas scroll animation that seamlessly takes users on an interactive journey through the storefront as they scroll down the page.

## ✨ Key Features
- **Cinematic Canvas Scroll Animation**: Smooth 300-frame image sequence with fluid spring interpolation (`0.085` damping factor) for an Apple-style glide, DPI retina scaling, progressive chunk preloading, and dynamic scroll prioritization.
- **Modern Luxury Dark Aesthetic**: Glassmorphism cards with translucent frosted glass, subtle neon accents, and high-contrast typography.
- **Complete Website Layout**:
  - **Navigation Header**: Single-line capsule navbar with desktop buttons and mobile hamburger drawer.
  - **Hero Section**: Clean headline (*Fresh Clothes. Happier Days.*) with cold-white bold subheading and dual CTAs.
  - **5 Feature Cards**: Advanced Fresh, Professional Touch, Customized Options, Superior Clean, and Exceptional Quality with interactive 3D perspective tilt.
  - **Services Section**: Editorial Playfair italic typography (*Laundry Care Made Effortless*), 4 detailed service cards, and certification standards.
  - **Stats Section**: Infographic glowing pillar meters (*10K+ Garments, 98% Satisfaction, 500+ Customers, 24/7 Booking*).
  - **Reviews Section**: Verified customer testimonials with 5-star ratings and verified indicators.
  - **Tailored Care Section**: Featured service cards with bespoke badges.
  - **Contact Section & Footer**: Complete location in Mumbai, helpline (`98340 54348`), email (`bumblewash26@gmail.com`), Instagram link, one-click copy buttons, and Back to Top navigation.
- **Interactive Modals & UI**:
  - Interactive "Send an Enquiry" booking popup with input validation and state management.
  - Toast feedback notifications for actions and copying.
  - Floating Back-to-Top quick jump and smooth section navigation.

## 🚀 Development & Build

# Start development server
